## 当前滚动计划

### Day 5：事务任务、affectedRows 守卫、排队取消、软超时、异步 shutdown

**目标：** 为后续真实库存事务做准备，尤其是入库确认、出库扣减和库存一致性。

**知识点：**

- 单 SQL 任务与多语句事务任务。
- 数据库事务的 `begin`、`commit`、`rollback`。
- `affectedRows` 作为数据库层业务守卫的意义。
- 为什么不能强杀正在执行的 `QSqlQuery::exec()`。
- 排队取消、软超时、关闭排空超时的区别。
- 异步 shutdown 与待处理任务清理。

**实施任务：**

- 补齐事务任务执行逻辑。
- 为需要守卫的语句增加 affected-rows 期望值。
- 事务中任意语句失败时执行 rollback。
- shutdown 或排空超时时取消待派发任务。
- 明确定义软超时后调用方能收到什么结果。
- 增加事务回滚、affectedRows 守卫、shutdown drain 测试。

**验收标准：**

- 事务中任意语句失败时，前面已执行语句全部回滚。
- 带守卫的 UPDATE 在 affected row 数不符合预期时会让事务失败。
- 待派发任务可以取消，但不强杀正在执行的 SQL。
- shutdown 行为确定，并能发出完成信号。

### Day 6：配置读取、IniHelper、ConfigManager、数据库配置装配

**目标：** 建立统一配置入口，让后续模块不再各自硬编码数据库、日志、队列等参数。

**知识点：**

- `QSettings` 读取 INI 文件的基本用法。
- 低层工具类 `IniHelper` 与业务配置类 `ConfigManager` 的职责边界。
- 默认值、必填项、类型转换、范围校验。
- 配置错误如何转化为结构化错误，而不是程序直接崩溃。
- 为什么业务模块最好依赖强类型配置对象，而不是到处直接读取 INI。
- 开发环境配置与生产环境敏感信息的区别。

**实施任务：**

- 在 util 或 config 模块中设计 `IniHelper` 的读取接口。
- 设计 `ConfigManager` 或等价类，把 INI 映射为 `DatabaseConfig` 等强类型配置。
- 提供默认配置文件示例，例如数据库、Executor、日志配置。
- 增加缺失配置、非法类型、越界数值、默认值读取测试。
- 将数据库模块初始化改为从配置对象获取参数。

**验收标准：**

- 配置读取逻辑集中在一个模块内。
- 数据库连接参数不再散落在测试或业务代码中。
- 缺失必填配置时能返回清晰错误。
- 测试可以使用临时 INI 文件独立验证配置读取行为。

### Day 7：日志模块、结构化日志、数据库模块运行诊断

**目标：** 给数据库模块和后续业务模块提供可追踪的运行日志，方便定位连接失败、SQL 失败和异步任务问题。

**知识点：**

- Qt 日志系统：`qDebug`、`qInfo`、`qWarning`、`qCritical`。
- `qInstallMessageHandler` 自定义日志输出。
- 日志级别、日志分类、日志格式。
- 文件日志与控制台日志的区别。
- requestId 在异步日志中的作用。
- 哪些信息不能写入日志，例如明文密码。

**实施任务：**

- 设计简单的 Logger 初始化入口。
- 支持日志级别和日志文件路径配置。
- 数据库 Executor 和 Worker 关键路径补充日志。
- 日志中带上 requestId、任务类型、错误码等诊断字段。
- 增加日志初始化和敏感信息过滤测试。

**验收标准：**

- 程序启动后日志输出位置确定。
- 数据库连接失败和任务失败能通过日志定位原因。
- 日志不会输出数据库密码等敏感信息。
- 日志模块不反向依赖数据库或业务模块。
