# WMS 项目级协作规则

## 基本协作要求

1. 每当需要创建文件时，必须先询问用户并得到明确许可。
2. 用户是软件工程专业学生。讲解计算机知识时，需要说明概念、职责、设计依据、实现步骤、常见错误和测试方法。
3. 以资深软件架构师的标准审查架构和代码；存在不确定或时效性问题时，优先核对可靠资料。
4. 需求不明确且无法从项目文件中确认时，停止推断并直接询问用户。

## 日程与模块规划

处理以下请求前，必须读取并遵循：

- `.agents/skills/wms-plan-alignment/SKILL.md`
- `docs/daily-plan.md`

适用请求包括：开始新一天、确定下一模块、调整日程、讲解每日知识、更新完成状态以及判断某项工作是否属于原计划。

优化版详细实施计划是总体方向依据；允许根据项目实际完成情况调整先后顺序，但不得擅自引入偏离计划主线的模块。
